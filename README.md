# Burnett-conjecture

This is the Lean development for **High-frequency vacuum limits with bounded first derivatives: a variational approach to the forward Burnett conjecture**. [GitHub Actions](https://github.com/Oho1e/Burnett-conjecture/actions)

The project is in `development`. The bilingual backfill starts at `a7e0b833d176342a58b68f43a94c1db6738e3a85`, which incorporates PR #16. This baseline has 401 inherited targets, 471 inherited inventory entries, and 131 inherited Lean sources. With the eight Ward support targets, this candidate has 409 targets, 479 inventory entries, and 139 Lean sources. [Ward statements](docs/statements/transport-ward.en.md) The local weak Ricci delivery has four modules, 32 declarations, and seven supporting targets, with independent source, type, and axiom review. Its coordinate vacuum premise is explicit. The intrinsic bridge, global tensor statements, and F04/F05 remain open in that delivery. New author confirmations remain pending as recorded. The required scope includes the rotating null moment obstruction to transport representation (X03) and the multiscale Rosen vacuum sequence with exact zero-source coordinates (X06). X03 entered `main` with PR #13, with author confirmation of the new interpretation tracked separately. X06 remains open. The work plan divides the manuscript into 46 slices.
