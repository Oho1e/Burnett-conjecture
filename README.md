This is the Lean development for **High-frequency vacuum limits with bounded first derivatives: a variational approach to the forward Burnett conjecture**. [GitHub Actions](https://github.com/Oho1e/Burnett-conjecture/actions)

The project is in `development`. This candidate contains 944 registered targets, 1009 inventory entries, and 974 Lean sources. The F04 local results identify the weak Ricci limit and prove strong H⁻¹ convergence of the actual linearized Ricci in each preferred chart under explicit coordinate vacuum. The intrinsic-curvature results identify the chart Ricci trace and derive that coordinate-vacuum premise from the same intrinsic vacuum sequence. The Ward batch adds eight supporting endpoints for the finite-dimensional variation, Fourier Hessian, and gauge cancellation. The global Einstein tensor moments have been implemented. The global intrinsic amplitude and its contraction to the original physical measure have been implemented. The F05 original operator pairing in arbitrary receiving charts, assembly of the paper's quadratic theorem, and the transport theorem remain open.
