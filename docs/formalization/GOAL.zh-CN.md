# 论文形式化目标与自动续接规则

2026-11-17按用户最新指令更新。本文是当前工程的持久目标约定；当前数学状态仍由scope和适用证据决定。

目标：按工作文件有序完成锁定论文全部正式数学结果、已确认关键未编号结果及必要依赖的Lean形式化，遵守信任A、独立反向复核和真实机器检查。文章、标准与信任范围不因此改变。

用户最新指令：

> 除非后续分支依赖前面的分支并入main，否则在完成上一个pull request后，自动推进下一个pull request的形式化工作。

据此执行：

- 一个PR完成适用的数学独审、当前完整候选检查、实际main组合CI与工件核对、并已可交给人类合并后，保存其受审版本和交接证据。PR待人工合并本身不再触发整个目标暂停。
- 检查依赖图和当前已就绪任务：有不需要等待该PR合入main的数学工作时，从适用的实际main建立独立分支/worktree，自动推进下一批证明、独审、检查和下一份PR。不要为了逐个等待人类合并而串行化独立工作，也不为此制造空PR。
- 后继分支确实需要前序PR先合入main时，先查是否还有其他独立任务。仅当没有可执行的独立工作，或遇到仍需用户决定的数学事项/确认的阻断时，保存证据并停止等待。不要把普通编译错误或可修复缓存问题自动提升为阻断。
- PR的最终main合并仍由用户执行。此规则不授权代理merge、auto-merge、强推、删除分支或发布验证标签。
- main前进后核实实际新main及其push CI；刷新受影响候选、范围登记和组合检查。独立数学源码的旧复核按实际输入差异复用，不能把旧CI冒称新组合已通过；中央文件冲突由协调者解决。

历史报告中的“就绪后暂停等人工合并”仅保留当时交接含义，不覆盖上述最新规则。目标未完成时不标complete；就绪PR、子代理同意及绿色CI均不等于整篇已验证。
