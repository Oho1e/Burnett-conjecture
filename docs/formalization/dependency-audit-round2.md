# F05 的两次延拓与下一接口

2026-11-16；Lean 4.24.0、mathlib `f897ebcf72cd16f89ab4577d0c826cd14afaafc7`。本记录细化第一轮调查的下一任务，不扩大原文假设、信任或认证范围。

## 已实现的一般工具

`Burnett.Analysis.Compactness.DenseTests` 从真实连续线性泛函序列 uₙ、一个显式统一算子范数界及稠密测试集上的收敛，构造全空间逐点收敛的唯一连续线性极限 L，保留同一范数界。它不要求测试空间完整，也不提供算子范数收敛。另有实际极限在误差趋零的非负下界下保持非负的工具。

这项一般定理不证明原PDO族已有这些前提。尤其有限阶符号导数控制不能直接替换成符号的 C⁰/sup 范数控制；不能将测试族的稠密性与一个未建立的范数界放进结构后称缺陷提取完成。

## 分开完成两次延拓

1. 沿同一共同子列，先由实际零阶算子的有限符号半范数界，将可数密集光滑测试上的极限扩到原缺陷测试类中的全部光滑符号。需要真实量化、基支撑及一致估计。
2. 对非负符号，通过真实平方分解/Gårding形状的趋零误差得到极限正性，再在固定支撑上用正的order-unit截断给 C⁰ 控制。使用保共同支撑的光滑逼近扩到整个真实 C_c 空间，核对线性、正性、独立性及局部兼容性。

第二步的界不能仅由第一步的有限阶半范数界推出。两个步骤继续保留同一子列和全部角向测试；实部和自伴代表的对应、低阶紧余项及测试中共轭约定须显式证明。

## RMK 的现有准确接口

固定库的 `Mathlib.MeasureTheory.Integral.RieszMarkovKakutani.Real` 提供 `RealRMK.rieszMeasure` 和 `RealRMK.integral_rieszMeasure`，输入为整个真实正实线性泛函 `C_c(X,ℝ) →ₚ[ℝ] ℝ`。该接口不要求先假设总质量有限或把连续性额外塞入输入。具体拓扑、Borel及正则性实例仍按实际使用核对。

本轮RMK本体及相关C_c/PositiveLinearMap模块缺少已构建缓存，**只作源码核签**，未记实际Lean调用通过。已有Content、Urysohn和SmoothApprox依赖下，正则性、紧集有限/局部有限、sigma-compact下全Borel内正则及固定嵌套截断的13项API和相应实例已实际核签。缓存缺失不等于库缺定理；后续消费者需要时再准备固定版本缓存并实际调用。

最邻近的实作是固定支撑正泛函的局部 C⁰ 控制及保共同支撑的正线性延拓。真实PDO有界性、Gårding误差、负一阶余项紧性、全局丛值测度、Gram协方差转换及a.e.系统核定位均仍开放。一般稠密延拓、RMK接口或半正定核引理分别只是这些消费者的输入，不能独自关闭F05。
