# 有限维变分与 Ward 恒等式

[English](transport-ward.en.md)

本批涵盖原文 V02、V04 和 V07 的有限维计算。在实际逆度规和 ΓΓ 密度上求度规路径导数，构造三种度规与动能位置的循环顶点。在标准 Minkowski 度规 η 上，将带 Fourier 负号的 Hessian 识别为迹反转后升指标的 Einstein 符号配对。实顶点对三个振幅分别线性，同时缩放三个频率时按二次齐次缩放。

复化使用复双线性或多线性配对。对满足带符号动量守恒的实协向量，复振幅取转置对称，非壳单规范恒等式具有原文 (J\cdot A(\mathcal L)) 的配对次序。对两条满足各自无迹与横向约束的屏幕腿，低规范公式有四项，分别保留输运相位差和三项自身相位。三条纯规范腿在动量守恒下给出零顶点。

八个模块共 229 项声明，登记八个支持目标。完整曲率作用量和散度代表的等价、一般 Lorentz 度规的协变与统一符号估计、规范腿频率分类和输运仍须闭合。Hermitian 能量及修正算子的伴随也有单独的证明义务。新增数学说明的作者确认待记录。
