# 任意坐标图的投影源

这一批实现锁定论文第 1600–1616 行的命题 4.1（`prop:general-projection`）。

`Burnett.P01.exists_originalGeneralProjection` 先固定原二次定理给出的同一子列、内禀张量协方差和物理余球面测度。对任意最大坐标图及紧支于图内的实光滑截断，用同一个固定实偶零阶 Fourier 乘子作用于截断度规扰动的实际零延拓。对任意 $1<p<\infty$，投影场在 $L^p$ 和 $L^\infty$ 趋零，梯度在 $L^p$ 一致有界。范数与散度源估计覆盖全序列。

给定共同 Lipschitz 上界后选取源常数。这个常数统一控制在截断支集邻域等于逆度规的各光滑延拓族和所有序列指标，散度源在整个坐标空间属于 $L^2$。

在同一原子列上，混合导数配对允许彼此独立的导数方向、张量分量和复值光滑零次齐次角乘子，并在两槽使用实际正则化投影。在截断等于一的窗口，投影后协方差限制在零特征集并满足 Lorenz 收缩。带四分之一系数的物理收缩在全部 Borel 集上等于同一原余球面测度的限制。原 Einstein 矩等式随同见证给出。
