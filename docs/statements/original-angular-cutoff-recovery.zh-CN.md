# 原角修正与截断恢复

证明在原文指定的径向与角度紧集上使用原有正则化角符号。球谐模态以同一个有限阶导数界构造前向算子及高槽伴随，Hermitian 角部分和具有二次衰减的角尾。固定角阶后，在算子两侧同时施加上频窗口的配对及弱散度项都收敛到去掉上频窗口的 Hermitian 算子对应项。

同一原算子对不同高槽场的混合弱能量估计使用常系数波源与散度源之和，系数只需控制到一阶导数。极限依次取固定角阶下的上频率极限、角阶极限。两步均在固定 Schwartz 场上进行，无需序列一致的 Schwartz 半范数。

投影源恒等式在系数拆成背景常量与 Schwartz 涨落后，把原投影场的散度源精确识别为冻结波算子与该涨落的散度算子之和。同一原补丁的参数选择和序列一致估计接续近远源配对。
