# 原投影补丁源与宽截断误差

`Burnett.C02.exists_originalTransportPatchFamily` 将锁定原文第 2647–2670、2714–2729、2731–2814 和 2852–2887 行的补丁构造、投影源与宽截断估计接到同一原场。固定一个相容坐标图，选择紧集 $K\subset\operatorname{int}K^+$，并给出包含 $K^+$ 的图内凸紧窗。输入沿用原内蕴真空列、局部一致收敛、紧集上一阶界和已提取的同一严格子列 $\sigma$ 与协方差 $A$。选取补丁尺度阈值前固定 $p>3$ 和原分量差的非负趋零上界 $e_n$。

在所有足够小的正尺度 $\ell$ 上，同一有限三次分割 $\sum_j\chi_j^3=1$ 具有导数消去 $\sum_j\chi_j^2\,\mathrm d\chi_j=0$，并提供外层平台截断 $\chi_j^+$。半径 $6\ell$ 的外球窗 $P_j$ 具有统一的重叠和体积和界。对每个补丁，取实际截断场 $z_n=\chi_j(g_n-g_0)$。物理投影 $u=\Pi_E(D)\chi_{\rm hi}(D)z_n$ 及其规范补场共享这个输入。物理投影的全空间散度源使用在原支撑附近与实际逆度规一致的延拓系数。第 $\sigma(n)$ 个源的 $L^2$ 界为
\[
 C\,|P_j|^{1/2}\bigl(1+\ell^{-1}+\ell^{-2}e_{\sigma(n)}\bigr).
\]
物理场、规范补场及其一阶导数都保留相应有限指数的补丁体积因子。

同一截断、同一 $\sigma$ 和 $A$ 同时给出实际宽屏误差与相位误差的全空间 $L^3$ 界。每项的最终上界为 $C_p\ell^\alpha |P_j|^{1/3}+\varepsilon$，其中 $\alpha=2(p-3)/(3(p-2))$，$\varepsilon>0$ 任意。常数和尺度上限先于补丁及序列极限选定。相应宽算子的有序梯度向量具有真实的 $L^3$ 可积性。

在选补丁尺度前固定薄锥厚度，还可得到第 2830–2834 行的两项实际薄屏梯度估计。薄锥证明中的两项输入误差使用同一个宽屏窗口。原变分输运在实际补丁上组合近角、薄屏、相位、远角与规范余项。 [原变分输运与正向动理学极限](original-forward-kinetic-limit.zh-CN.md)
