# 定量联合 Fourier 乘子估计

[English](joint-fourier-multiplier-estimates.en.md)

这些声明给出原文第 660–671 行调用的联合乘子三线性估计。实符号 \(m\) 定义在联合频率空间 \(\mathbb R^4\times\mathbb R^4\)，在零点外光滑，并对正伸缩零次齐次。三个输入是在 \(\mathbb R^4\) 上的复 Schwartz 函数。第三个 Fourier 测试在 \(-(\eta+\xi)\) 取值。

- 对尺度 \(2^{i-N}\)（\(0\le i<2N\)）的实际物理块做有限求和并测试，取下端与上端截断同时移除的极限，得到实际联合 Fourier 积分。
- 若 \(p,s,z\) 都在 \((1,\infty)\) 内且 \(1/p+1/s+1/z=1\)，三线性配对绝对值由三个 \(L^p,L^s,L^z\) 范数的乘积乘以实际参考核矩的线性组合控制。核矩的权重阶数为 \((j,k)=(1,1),(5,1),(1,5)\)，组合的有限系数依赖指数和固定窗。
- 若联合欧氏单位球面上 0 至 15 阶环境 Fréchet 导数有共同界 \(D\ge0\)，则配对界为 \(K D\|f\|_p\|g\|_s\|h\|_z\)。球面半范数使用固定的线性坐标拆分。常数 \(K\) 先于 \(m,D\) 和三个输入场选定。
