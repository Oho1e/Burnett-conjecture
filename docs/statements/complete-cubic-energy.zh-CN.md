# Lean 库中的完整三次能量

[English](complete-cubic-energy.en.md)

证明对应锁定原稿第 601–729 行，沿用实际双线性 Fourier 估计的定义。第 730–734 行的应用在冻结和输运切片中处理。

- 对有限指数 \(p,s,r>1\) 且 \(r^{-1}=p^{-1}+s^{-1}\)，Schwartz 系数 \(f\) 的实际交换子作用于 Schwartz 输入 \(g\)，结果属于 \(L^r\)。实值符号在零点外光滑且对正伸缩一次齐次。四维单位球面上 0 至 16 阶环境导数的共同界 \(D\) 给出 \(KD\|Df\|_p\|g\|_s\) 的估计，\(K\) 与 \(b,D,f,g\) 无关。\(Df\) 是复值系数的实 Fréchet 导数。频率沿用原文约定。
- 固定齐次符号的连续性定理用 \(u-v\) 的欧氏梯度阵列 \(L^3\) 范数，以及两场梯度范数和的平方，估计两份完整三次能量的差。能量同时包含实际拟线性二阶导数项和常系数二次一阶导数项，矩阵系数满足原文的转置对称。库中另有常数为 \(KD\) 的定量版本。齐次极化估计控制实际对称三线性映射，用三槽梯度范数的乘积。场为固定正交坐标下的实 Schwartz 场。
- 固定实值 Schwartz 剖面 \(\chi,d\) 后，正则化的对称三线性映射在对角线上等于符号 \((1-\chi)b+d\) 的实际完整能量。给定剖面和系数阵列，估计使用常数 \(K(D+1)\) 和三槽欧氏 \(W^{1,3}\) 范数的乘积。每项 \(W^{1,3}\) 范数是场值阵列和完整梯度阵列的两个 \(L^3\) 范数之和。
- 固定正则化连续性定理允许指定一个在某球外等于齐次符号的实光滑符号。证明固定原点附近为一、某球外为零的实截断，再构造光滑紧支撑的余项。能量均使用原来指定的符号，差值由 \(u-v\) 的 \(W^{1,3}\) 范数和两场该范数和的平方控制。常数在选择两场之前随正则化确定。
- 对自身及完整梯度的 \(L^\infty\) 范数有限的实光滑 \(f\)，以及实光滑紧支撑 \(H\)，混合拟线性估计控制两个有序配对之和的虚部绝对值，界为 \(KD\) 乘 \(\bigl(\|f\|_{\infty}\|\partial H\|_3+\|\partial f\|_{\infty}\|H\|_3\bigr)\|\partial u\|_3\|\partial v\|_3\)。取 \(u=v\) 后得到原文的加权拟线性能量。
