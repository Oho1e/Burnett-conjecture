# 辅助单位截面的加权推前

证明对应锁定论文第 481–485 行的 `eq:norm-change`。在辅助度量 $r$ 的原单位余球丛上，记 $s_0(x,\xi)=|\xi|_{r'}$，并令 $F_0(x,\xi)=(x,\xi/s_0)$。该映射保留基点。两个辅助度量共用原真空序列的同一次严格细化、同一组取图截断以及同一组局部矩阵测度见证。两种物理测度均由各自的原内蕴振幅协方差收缩得到。

迹控制测度的变换权重为 $s_0^2t$，其中 $t$ 是原协方差在新度量下的迹。把新密度拉回同一基点的纤维后，它几乎处处等于原密度乘 $t^{-1}$。因子 $t$ 消去。对每个收缩后可积的复值纤维实线性试验，对应的复测度在所有 Borel 集上满足加权推前。试验可以依赖新余球丛上的整个点。物理测度满足 $\mu'=F_{0*}(s_0^2\mu)$。

共同见证的构造采用非空底流形，并在两个辅助度量下保留全部具有局部表示的经典配对。四条支持定理对应换截面证明。完整二次定理与输运定理各有范围登记。支持结果已通过独立数学复核及原生重放，作者确认待登记。
