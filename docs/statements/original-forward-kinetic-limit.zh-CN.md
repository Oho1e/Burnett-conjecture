# 原变分输运与正向动理学极限

`Burnett.PaperStatement.variationalTransport` 对应原文第 1729–1735 行。
给定二次定理所用的同一子列及物理测度，见证包含相应的内蕴振幅。结论适用于穿孔余切丛上每个光滑、正一次齐次且底支撑紧的实测试函数。Hamilton 导数在限制到单位余球面前取。

`Burnett.PaperStatement.forwardKineticLimit` 对应原文第 139–168 行。
原假设给出一条子列及其对应的非负 Radon 测度。该测度在底上局部有限，集中在零壳上，给出 Einstein 张量矩、标量曲率消失和变分输运。在每个内禀全局双曲开区上，全动量测度从这一个余球面测度的限制构造。它在紧底集上具有有限二阶矩，满足全部紧支撑光滑对称张量的 Einstein 方程和全部紧支撑光滑全动量测试的输运方程。

两个结果使用原真空序列的局部一致收敛及紧集上的一阶导数界。二次构造先固定子列、内蕴振幅和物理测度。变分步骤在实际 C03 补丁上组合近角、薄场替换、相位、远角和规范项。角参数先于空间尺度选取。在两个尺度固定时先取序列极限，在角参数固定时令空间尺度趋零，最后令角参数趋零。
