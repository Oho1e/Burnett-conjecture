# 内禀曲率、Ricci 迹与图内真空

[English](intrinsic-curvature-Ricci.en.md)

本批为原文第 99–104 行的几何数据和第 352–388 行的坐标曲率计算提供八项支持结果。六个模块共含 14 个定义和 50 个定理。

从已实现的全局 Levi-Civita 导数和 mathlib 的流形 Lie 括号定义曲率。对光滑向量场，图内公式消去由向量场一阶、二阶 jet 引入的项，证明固定点的曲率只取决于三个切向量的值。利用原文的 Hausdorff 条件，每个切纤维的向量可由全局光滑截面实现。由此构造连续三线性纤维曲率，证明它在包含该点的任意两张 preferred 图中一致，并在全局光滑场上等于原曲率算子。

对固定切向量 U、V，Ricci 取切纤维上 X ↦ R(X,V)U 的实际线性迹。用切标架与图微分给出的共轭识别，该迹在坐标基下正好给出原文正号的 Σₐ Rᵃ_{b a d}，即已用于局部分析的 `coordinateRicci`。因此，同一光滑对称非退化度规序列满足内禀 Ricci 真空时，`sequence_coordinateVacuum_of_intrinsic` 给出每张 preferred 图的目标域内逐项坐标真空。

这项桥接结论可供局部弱 Ricci 极限和局部强 H⁻¹ 结论使用。完整 Lorentz 符号与时间定向模型、全局测试拼合、共同缺陷测度及作者确认仍各有后续工作。
