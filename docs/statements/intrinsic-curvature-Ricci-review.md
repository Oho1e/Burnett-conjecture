# 内禀曲率与 Ricci 迹的独立复核

[English](intrinsic-curvature-Ricci-review.en.md)

独立代理分批从实际 Lean 类型回读曲率算子、连接系数与坐标缩并、向量场 jet 消去、全局光滑截面、纤维张量及 Ricci 迹。完整 64 项冻结源码通过独立编译、类型与传递公理检查。六个正式模块保留相同的证明正文、定义和声明。复核证据及各模块源码由[源码绑定](intrinsic-curvature-Ricci-source-bindings.json)关联。

核对了 Lie 括号次序、纤维参数的次序及坐标 Ricci 的正号。在同一点的任意两张优先图，曲率的纤维值一致。点上的 Ricci 来自切纤维真实线性迹。真空桥对每个序列指标和图内点都使用同一个度规给出的真实 Ricci，而图外没有坐标真空断言。

六个正式模块曾通过 Lake 构建。另一次查询以这些正式模块及局部分析模块导入，实际核对了 64 个内禀声明及一个后续消费者的类型与传递公理，只使用约定的三项公理。本批登记八个内禀支持目标。后续消费者需要局部强 H⁻¹ 模块，作为单独交付继续推进。Lorentz 符号与时间定向、全局张量测试和 F05 缺陷测度仍待完成，作者确认待记录。
