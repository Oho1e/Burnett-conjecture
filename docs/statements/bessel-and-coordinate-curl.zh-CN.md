# F05 一阶定位与原度规列的坐标旋度

对 Schwartz 输入，Bessel 作用的 \(L^2\) 范数平方等于该输入的负阶 Fourier 能量。取固定的有限一阶行，系数均为实光滑紧支撑函数，可含固定零阶项。输入为光滑实分量列，每个分量在全空间 \(L^2\) 中一致有界，共用一个紧支撑截断且在任意分量非零处等于一，并在所有实光滑紧支撑测试下趋于零。若实际一阶行作用的负阶 Fourier 能量趋于零，则该行的齐次主角向作用在 \(L^2\) 中强趋于零。

对原度规扰动，背景光滑非退化，度规列光滑并在辅助度规 \(r\) 下局部一致收敛至背景度规 \(g_0\)，且扰动的内在一阶导数相对于背景几何体积具有一致的局部 \(L^\infty\) 界。在任一点选定的固定坐标图中，各扰动分量的一阶坐标导数在图像内每个紧集上一致有界。取固定光滑截断 \(\chi\) 紧支撑在图像内，第二个光滑紧支撑截断 \(\theta\) 在 \(\chi\) 的拓扑支撑上等于一，则作用于 \(\chi\partial(g_n-g_0)\) 的实际坐标旋度主角向行沿原序列在 \(L^2\) 中强趋于零。

含曲率的协变旋度恒等式、共同缺陷密度上的压缩以及变系数 Ricci 行仍是后续步骤。

移植保留四个已证 Bessel 命名空间块及原旋度定理体，将捆绑式导入换成明确的主库模块导入。既有红外模块把分布测试中乘固定实紧支撑权重的引理开放给跨模块引用。该引理的陈述和证明沿用原文。源码与对象检查使用锁定 Lean 和 Mathlib，并核对旧输入在已验基线与编译验证树中的源码一致。
