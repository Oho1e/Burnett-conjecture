# 角核的坐标变换与质量加权

[English](angular-kernel-transforms.en.md)

原文比较不同辅助度量的单位余球壳上的物理测度，并用条件角测度分解相空间测度。以下辅助结果说明，给定分解在可测换坐标及非负加权后如何重构测度。其几何应用见锁定原文第 481–485、494–515 行。

| Lean 声明 | 数学结论 |
| --- | --- |
| `coordKernel_integral_sections` | 对 s-有限的底体积和条件核 k，以 b 变换底坐标，在可测逆映射给出的原基点取 k，再将角测度沿 φ 推前。若底坐标的逆几乎处处恢复原基点，所得截面积分就在每个可测联合事件上给出原联合测度的推前。 |
| `coordKernel_real_moment` | 可测实函数对坐标核的 Bochner 积分等于其拉回对原条件角测度的积分。物理二阶矩的可积性及其与 Einstein 张量的对应还需要后续估计。 |
| `reweightedKernel_apply` | 在每个基点，新条件核等于对原条件角测度乘以非负可测权 w 后沿 F 推前的测度。 |
| `reweightedKernel_reconstruct` | 设原测度 μ 在每个可测事件上等于 s-有限条件核对底测度的积分。变换后的条件核在每个可测目标事件上重构 wμ 沿 F 的推前，事件质量可以无穷。 |

更换辅助度量时，F 将协向量除以它在新度量下的范数，w 取该范数的平方。本包提供相应的测度运算。原真空序列、具体几何映射及角测度的识别由后续几何证明承担。当前库版本中父推论仍待完成，作者确认待记录。[源码绑定](angular-kernel-transforms-source-bindings.json)
