# 实际双线性与标量 Fourier 乘子

[English](bilinear-fourier-operators.en.md)

这些声明构造原文第 660–677 行 Fourier 估计所用的物理算子。物理变量均为四维。对 Schwartz 输入，实际双线性输出与第三测试函数的配对在第三 Fourier 因子中取负输出频率 \(-(\eta+\xi)\)。按原文换到弧度频率时使用 \(\tau=2\pi\)。

- 若 \(p,s,r>1\) 有限且 \(r^{-1}=p^{-1}+s^{-1}\)，实值联合符号在零点外光滑且对正伸缩零次齐次，则 Schwartz 输入的实际双线性输出属于 \(L^r\)。固定八维坐标中，在联合单位球面取值的 0 至 15 阶环境 Fréchet 导数的共同界 \(D\) 给出 \(\|T_m(f,g)\|_r\le K D\|f\|_p\|g\|_s\)。常数 \(K\) 先于符号和输入选定。
- 谱输入结论适用于两个 \(L^1\) 谱，要求它们在零点外光滑，逆 Fourier 变换分别属于 \(L^p,L^s\)。同一环带逼近同时在 Fourier \(L^1\) 及相应的物理范数中收敛。
- 对 Schwartz 输入和实值可测有界联合符号，在实际 \(L^2\) 输出上再施加由实值可测有界符号实现的 Fourier 乘子，所得函数几乎处处等于在 \(\eta+\xi\) 处取外置符号值的实际联合积分。若联合符号和外置符号均为实值、在零点外光滑且对正伸缩零次齐次，则该合成积分对上述谱输入也有 \(L^r\) 界。
- 实的零次齐次、零点外光滑标量符号在每个有限 \(p>1\) 的 \(L^p\) 上均有有界实现，在共同定义域与 Fourier \(L^2\) 乘子一致，并在 Schwartz 输入上与弧度归一化的作用一致。径向和角向因子的谱属于 \(L^1\)，在零点外光滑，逆变换属于这些有限指数的物理 \(L^p\)。
