# X04 实际几何的非表示性

[English](bianchi-counterexample.en.md)

Lean 声明 `Burnett.Bianchi.exists_bianchi_intrinsic_counterexample` 对应锁定稿第 3245–3247 行的 `prop:bianchi`，证明见第 3248–3301 行。对任意 $H>0$，由原文的初值和关于 $\gamma,A,\rho$ 的实际有限维系统，在 $0<\tau<\pi/4$ 的开乘积 $(-\tau,\tau)\times\mathbb R^3$ 上构造同一个光滑度规。

由实际曲率取迹得到 Einstein 张量。Lean 验证了每个切纤维上的 Lorentz 符号、实际度规迹为零，以及在任意切向量上的正半定性。每一点的两个非零零协向量都在实际余切纤维中，其外积平方以正系数组成同一个 Einstein 张量。沿开乘积的实际坐标图缩并该张量的协变导数，所得散度为零。

非表示性结论覆盖每一种光滑正定辅助度量及其单位余切截面上的任意局部有限非负测度。候选必须同时满足零锥支撑、所有对称紧支撑张量矩，以及所有底支撑紧致、对协向量的正数缩放一齐次的光滑 Hamilton 测试。换到欧氏截面时，将每个协向量 $p$ 送到 $p/a(p)$ 并把测度乘以 $a(p)^2$ 再推前。同一个新测度保持零锥支撑、矩恒等式和输运恒等式。积分使用实际 Hamilton 函数和几何体积。

反证使用同时适用于两个时间片的光滑角向乘子 $-2\xi_0/(\xi_0^2+\xi_{\rm sp}^{T}\gamma^{-1}\xi_{\rm sp})$。测度的非负性和横向矩迫使输运测试的分子在底截断非零处消失。$11$ 分量的矩恒等式给出严格负的输运积分。
