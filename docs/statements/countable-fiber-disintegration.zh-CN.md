# 可数覆盖上的测度分解

[English](countable-fiber-disintegration.en.md)

推论 `cor:base-marginal` 的证明先在紧耗尽上构造条件概率，再乘以基底密度得到角测度，并断言固定物理测度的分解几乎处处唯一。三个 Lean 模块在一般可测空间 `X,Y` 上实现这一步测度论构造。原文位置为第 494–502、511–515 行。

| `Burnett.F08.FiberGluing` 中的声明 | 数学结论 |
| --- | --- |
| `localFiberKernel_unique_of_integral_sections` | 基底测度有限时，给定一个有限核，任何可测核若在每个联合可测集上给出同一截面积分，就与该有限核几乎处处相等，等号表示两纤维测度相等。可数性条件为基底类型可数或纤维的 σ-代数可数生成。 |
| `patchKernel_disintegrates` | 在可数可测覆盖上，各片有限核若表示同一联合测度的相应限制，就能拼成表示该联合测度的核，每个纤维的质量都有限。各片可有各自的界。 |
| `patchKernel_unique_of_integral_sections` | 若基底测度在每片上有限，则在与局部唯一性相同的可数性条件下，对固定联合测度的全部可测集给出截面积分表示的任一可测核都与拼接核几乎处处相等。 |
| `exists_weighted_disintegration_on_cover` | 给定第一边缘测度和可测关系上的集中性，可在原基底测度上得到一个 s-有限核，同时具有下述质量、集中性和唯一性。 |

最后一条中，基底测度 `v` 为 s-有限，纤维 `Y` 为非空标准 Borel 空间，非负联合测度 `ρ` 的第一边缘等于 `v.withDensity w`。非负扩展实值权重 `w` 可测，且在可数可测覆盖的每片上有有限上界。基底测度及联合测度在每片及其基底逆像上的限制分别有限。联合测度在可测关系 `Z` 的补集上取值零。

同一个拼接核 `k` 满足 `v ⊗ₘ k = ρ`。对每一个基点 `x`，纤维都是有限测度，总质量恰为 `w x`，故在 `w x = 0` 处纤维为零测度。对几乎每个 `x`，该纤维在关系 `Z` 的相应截面的补集上取值零。任何可测核若对**同一联合测度**的每个联合可测集给出截面积分表示，就在一个基底零测集外与 `k` 逐点相等为测度。竞争核无需预设有限性。所选代表在全部基点上都满足质量公式，包括唯一性结论容许的例外点。

仅加权存在性定理使用非空标准 Borel 纤维。拼接本身适用于一般可测空间及 s-有限基底测度。即使各片的有限界沿覆盖增大，局部表示对应同一联合测度的各自限制，也足以恢复全局联合测度。辅助定理 `patchKernel_ae_of_local` 将各片几乎处处成立的纤维性质传至拼接核。

四项登记均为切片 F08 的支持目标。几何应用仍需给出内禀相空间与投影、`π_* μ = e_r dV`、局部有限性与局部密度界、单位零壳集中性及应力张量矩公式。此交付阶段的母推论保留未闭合状态。独立数学回读和人类语义确认待登记。
