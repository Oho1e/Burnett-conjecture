# 全局内蕴振幅协方差与原物理测度

固定辅助 Riemann 度量 r。从任意原真空严格子列再作一次严格细化，得到原图见证以及实际 r 单位余球丛上的正则正控制测度 τ。τ 在任何紧底集的原像上有限。实切空间纤维上的复值四线性振幅对 τ 可测，且其协方差矩阵半正定、辅助迹为一、内蕴 Ricci 主符号为零，这些性质均在 τ 几乎处处成立。其有序复条目测度恢复原图振幅。在两个相容图的紧窗口上，Borel 换图律使用实际余切相位变换与每个有序指标对的两个 Jacobian 因子。

在零壳上，按背景逆度量取四分之一实收缩即可恢复原正物理测度。其支撑、标量曲率恒等式以及所有紧支撑光滑对称张量 Einstein 矩均来自同一细化子列。在非空底流形上比较两个辅助度量时，保留同一原子列和逐图见证。记 F 为径向换截面，α 为接收度量的范数平方，t 为旧振幅在接收度量中的迹。新控制测度是 F 推前 αtτ，新振幅经 F 拉回后等于旧振幅除以 t，几乎处处成立。新物理测度是 F 推前 αμ。单度量结果也覆盖空底流形。

局部配对使用原体积半密度梯度与两个独立光滑截断。截断支撑在有原见证的紧图窗口上，所给有界 L² 算子须有实际的局部左 Fourier 表示及紧余项。实值零次齐次主符号给出按论文内积顺序写出的极限，所用振幅为同一全局振幅在窗口上的限制。满足所列导数估计的紧底支撑负一阶光滑符号给出紧余项。接收图中已有有限见证平台覆盖。任意接收图上的实际经典算子配对、F05 的全局装配、论文二次定理与输运仍待完成。本批支持结果尚无作者语义确认记录。
