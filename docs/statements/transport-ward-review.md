# Ward 有限维公式的独立复核

[English](transport-ward-review.en.md)

独立代理逐批回读 229 条冻结声明的真实 Lean 类型与定义。复核包括逆矩阵与密度的真正导数、Fourier 两个虚数因子的负号、实际 Einstein 配对、各槽的线性和共同频率齐次性。复配对按转置对称振幅延拓，保留实际 Lie 表达式。只在相应消去推论中使用真 Ricci 核假设。

屏幕回读保留各自的横向与无迹条件，以及输运相位差之外的三个独立项。独立精确算例中，输运相位差为零时其他项仍可非零。三纯规范消去保留带符号动量守恒。用于三腿代数的复双线性配对与后续需要的 Hermitian 配对分别核对。

八模块拆分复编中的 229 份类型与公理输出，与独立复核的组合稿逐字一致。[源码绑定](transport-ward-source-bindings.json) 记录全部声明所属模块、旧依赖哈希及实际生产路径核验。V02、V04、V07 与输运主定理均保留未闭合状态，作者确认待记录。
