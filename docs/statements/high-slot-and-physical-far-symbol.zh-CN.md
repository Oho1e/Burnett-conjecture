# 高槽交换子与实际物理远角精确符号

高槽证明对应论文引理 `lem:analytic-correction-bounds` 第 1454–1465 行。原正则化笛卡尔符号满足高输入 (L^2) 估计，两组指数的角导数界使用同一有限阶阈值，实际高槽伴随也在相同符号拓扑下满足粗糙系数交换子估计。同尺度系数分支使用正式库已有的 Carleson 堆积估计。

物理远角符号对应变分输运证明第 2504–2556 行。实际薄屏上的两条高频红外窗与径向守卫满足精确的支撑恒等式，远角系数在所需角窗的独立变量上光滑延拓。在物理支撑上，有符号相位乘回受保护的商可恢复原完整分子。高槽伴随保留原有的截断窗，也覆盖频率轴上的情形。

把这些结果应用到同一原补丁的近远区估计，仍需要接入角算子恢复和成对的原投影源。完整校正引理与变分输运定理仍待完成。
